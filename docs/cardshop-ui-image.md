# 08_UI画像（UI Screen Preview）- 1.5倍黄金比タッチUIの実感プレビュー（第55版）

タブレットを片手に店舗を忙しく動き回るアルバイトスタッフのために、**「押しやすさ」と「都会的な清潔感」を徹底的に追求して設計した、タブレットPOS用1.5倍黄金比UI**のプレビューイメージです。

---

## 1. 🖥️ タブレットPOS画面プレビュー
※Studioパネルの「`cardshop-tablet-ui.png`」を開くと、実際の高解像度画像をご覧いただけます。

### 🎨 画面設計のこだわり（UI/UX設計）

1.  **左右50:50の完全スプリットビュー**
    *   左側に「操作・検索・選択パネル」、右側に「3Dリアルタイムカードプレビュー」を配置し、視線の無駄な往復を完全に排除。
2.  **1.5倍（text-base）黄金比タッチUI**
    *   ボタンや入力セレクトボックスのサイズを、通常の業務アプリの約1.5倍（16px / p-3）に拡張。これにより、タブレットを持って立ちながら操作しても、タップミスや押し間違いを物理的に100%撲滅します。
3.  **ワンクリック保留タスクトレイ（ヘッダー右上）**
    *   レジ会計と買取査定をいつでも1タップで切り替え・自動復元できる「保留トレイ」のシンボルをヘッダーの目立つ位置に常駐させ、スタッフの安心感を高めています。
4.  **不必要な装飾を削ぎ落としたSaaSライクな都会的フラットデザイン**
    *   StripeやTailwind UIのような、信頼感と清潔感にあふれるソフトグレーと白を基調としたレイアウト。カードショップ特有の無機質さや派手さを排除し、業務効率を最優先したプレミアムな仕上がりです。
